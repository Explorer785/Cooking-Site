# «Готовь вкусно!» — лабораторная работа № 4 (JavaScript)

## Что реализовано

Проект продолжает лабораторную работу № 3: сохранены страницы сайта, поиск рецептов на PHP и гостевая книга с хранением в MySQL. Дополнительно реализовано индивидуальное JavaScript-задание — калькулятор порций для рецептов.

На странице каждого блюда посетитель может уменьшать или увеличивать количество порций от 1 до 12. JavaScript автоматически пересчитывает количество продуктов относительно базового количества порций конкретного рецепта. Кнопка «Сбросить» возвращает исходное количество. Для пасты, сырников, салата и шакшуки базовое значение — 2 порции, для супа — 4 порции, для овсяной каши — 1 порция.

Новые фотографии не добавлялись. Используются только три изображения из исходного проекта: паста, сырники и куриный суп. Для остальных блюд сохранены пустые области.

## Требования

- XAMPP;
- PHP с расширениями `PDO` и `pdo_mysql`;
- MySQL или MariaDB;
- современный браузер с поддержкой JavaScript.

Если PHP сообщает `could not find driver`, проверьте в XAMPP файл `php.ini`: расширение `pdo_mysql` должно быть включено (строка `extension=pdo_mysql` не должна начинаться с `;`). После изменения перезапустите Apache и встроенный сервер PHP.

## Подготовка базы данных

Если база данных ещё не создана:

1. Запустите Apache и MySQL в XAMPP Control Panel.
2. Откройте `http://localhost/phpmyadmin`.
3. Импортируйте файл `database/gotov_vkusno.sql`.
4. Проверьте настройки в `config/database.php`.

Если вы уже сделали лабораторную № 3 и используете ту же базу `gotov_vkusno`, повторно импортировать SQL-файл не требуется.

## Запуск

Откройте PowerShell в папке `lab4-javascript` и выполните:

```powershell
C:\xampp\php\php.exe -S localhost:8000 -t public
```

Откройте `http://localhost:8000`.

## Как проверить JavaScript

1. Откройте каталог и выберите рецепт, например «Паста с томатами».
2. Найдите блок «Калькулятор порций».
3. Нажмите `+`: количество порций станет 3, а количество каждого измеряемого ингредиента изменится пропорционально.
4. Нажмите `−`: количество вернётся к 2 порциям.
5. Нажмите «Сбросить»: калькулятор вернётся к исходному значению.
6. Проверьте, что нельзя установить меньше 1 или больше 12 порций.

## Как работает скрипт

Файл `public/assets/js/recipe-calculator.js` ждёт загрузки HTML-страницы, находит калькулятор и список ингредиентов. Для каждого продукта берётся базовое количество из атрибута `data-base-amount`. Затем вычисляется коэффициент `текущее количество порций / базовое количество порций`, после чего обновляются значения на странице.

Например, для пасты базовый рецепт рассчитан на 2 порции и содержит 200 г пасты. При выборе 4 порций скрипт выводит 400 г.
